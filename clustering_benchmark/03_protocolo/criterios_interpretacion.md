# Criterios de interpretación

## Se puede afirmar

- “El algoritmo produjo N clusters.”
- “La solución tiene silhouette X.”
- “C1 presenta mayor proporción de ceros que el resto.”
- “La asignación es estable entre determinadas semillas.”
- “K-means y Ward muestran concordancia ARI X.”
- “Una estructura similar reaparece en dos meses.”

## No se puede afirmar sin evidencia adicional

- “Existen N tipos reales de clientes.”
- “Este cluster representa clientes que se van por Visa.”
- “El algoritmo descubrió una causa de churn.”
- “Silhouette confirma que los clusters son verdaderos.”
- “Una separación visual en UMAP demuestra grupos reales.”

## Lenguaje preferido

Usar:
- compatible con;
- asociado a;
- presenta;
- se caracteriza estadísticamente por;
- muestra mayor/menor;
- hipótesis de perfil.

Evitar:
- causa;
- verdadero tipo;
- segmento natural;
- definitivamente;
- demuestra que se va por.
